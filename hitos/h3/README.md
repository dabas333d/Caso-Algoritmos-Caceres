CASO DE ESTUDIO

El proyecto está basado en un sistema de gestión de inventario de computadoras. 
La organización administra aproximadamente 5000 equipos informáticos y registra asignaciones, movimientos, disponibilidad y procesos relacionados con la administración del inventario.



PROCESO DE TRABAJO

Durante el desarrollo del caso integrador fui adaptando los conceptos vistos en la materia al contexto de un inventario de computadoras, aplicando estructuras de datos, análisis de algoritmos, árboles, tablas hash, grafos y técnicas de optimización para resolver problemas asociados a la gestión de equipos.
